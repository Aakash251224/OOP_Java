# Java Basics and OOP Concepts

This repository contains beginner-friendly Java programs designed to practice core programming concepts and Object-Oriented Programming (OOP). The project is organized into separate sections to make learning Java easier and more structured.

## Repository Structure

.
├── java_basics
│   ├── DataTypes.java          # Demonstrates Java data types and variables
│   ├── Inputs.java             # User input using Scanner class
│   ├── Operators.java          # Arithmetic and increment operators
│   ├── Conditional.java        # if-else conditions and grading system
│   ├── SwitchCase.java         # switch-case statement examples
│   ├── ForLoop.java            # for loop examples
│   ├── WhileLoop.java          # while loop and infinite loop example
│   ├── DoWhile.java            # do-while loop demonstration
│   ├── TypeCasting.java        # Implicit and explicit type casting
│   └── Identifiers.java        # Java naming conventions and identifiers
│
├── oop_concepts (Coming Soon)
│   ├── ClassObjectDemo.java        # Basics of classes and objects
│   ├── InheritanceDemo.java        # Parent-child relationship example
│   ├── PolymorphismDemo.java       # Method overloading and overriding
│   ├── EncapsulationDemo.java      # Data hiding using getters/setters
│   └── AbstractionDemo.java        # Abstract classes and interfaces
│
└── README.md

## Java Basics

The `java_basics` section includes important beginner-level Java topics:

- Variables and Data Types
- User Input with Scanner
- Arithmetic and Logical Operators
- Conditional Statements
- Loops (for, while, do-while)
- Type Casting
- Naming Conventions and Identifiers

These examples are written in a simple and easy-to-understand format for practice and learning purposes.

## OOP Concepts

The `oop_concepts` section focuses on the fundamental principles of Object-Oriented Programming:

- Classes and Objects
- Inheritance
- Polymorphism
- Encapsulation
- Abstraction

More OOP examples and mini projects will be added gradually.

## Purpose of This Repository

- Practice Java programming
- Understand OOP concepts clearly
- Improve coding structure and readability
- Prepare for lab exams and academic projects
- Maintain Java codes with GitHub version control
